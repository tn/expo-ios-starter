# Contributing

Thanks for considering a contribution.

## Quick start
- Use Bun for installs and scripts.
- Keep changes small and focused.
- Run `bun run lint` before opening a PR.

## Development
```bash
bun install
bun run ios
```

## Code style
- Follow the existing patterns in `src/`.
- Use TypeScript types consistently.
- Avoid large formatting-only changes.

## Submitting changes
1. Create a branch from `main`.
2. Make your changes with clear commit messages.
3. Ensure lint passes.
4. Open a PR with a concise description and screenshots if UI changes.

## Issues
If you find a bug, open an issue with reproduction steps and environment details.
